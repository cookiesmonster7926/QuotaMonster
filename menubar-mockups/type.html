QuotaMonster · THE READOUT

A precision numeral with a cursor in front of it and an index behind it. The cursor is alive or at rest; the figure is whichever window is actually binding; the index names the other one. Nothing is bolted on — every signal is a property of one three-part line of type.

The grammar, left to right. cursor — at rest it is an underscore; working, it is a block whose height is the agent load (1 → 10+).  figure — the window that actually binds, in tabular numerals; the tenths digit ticks at the true burn rate.  index — the other window, named by its letter (D18 = 7-day at 18%). Because the index is named, both windows are always identified by one letter.

The anti-habituation mechanism is not brightness, it is a number that grows because you ignored it. The stimulus is never the same twice: 0m outlined, 2m amber, 7m red-inverted, 23m red-inverted and wider. Habituation needs a constant to attach to and there isn't one.

This is the honest half of the integration the brief asked for: activity is the rate at which quota is consumed, so activity does not need its own mark. The digit that is already on screen simply moves at the speed of the burn. Nothing is animating — a digit is being substituted, the way a clock substitutes its minutes. The cursor height gives the instantaneous read; the tick rate is the confirmation.

Idle. Cursor is an underscore at 50% ink, tenths frozen on 28.4%. Zero pixels are moving.

A session starts, then a second and third. The cursor stands up and grows: 1 → 3. Tenths begins to tick.

Fan-out: 7 agents. Cursor near full height; tenths substitutes every 3.9s at 92%/h — .4 → .5 → .6.

Projection has held past reset for 60s, so the instrument changes range: 28.4% becomes 47m, bold, ruled. Still monochrome.

Agents finish. Each one: cursor thickens 180ms, steps down one, ink decays to rest. Rapid finishes keep it lit — that is the fan-out reading as one event.

Drained to zero. Last flash settles over 900ms into the rest mark, range returns to 28.7%. Termination rule: the resting state is the idle state.

f1-e3 hits a permission prompt. The readout stops being a number: slab in 260ms, wait clock 0m → 1m → 2m, one 250ms knock per minute. The stalled agent stays drawn inside.

Answered. Slab retracts in 300ms, the figure comes back, and the parked agent resumes — the cursor stands up again.

Finished. 900ms settle, then nothing. The object is at rest and will not move again until something happens.

Honest timing: every duration above is the shipping duration — 180ms thicken, 700ms ink decay, 900ms settle, 260ms slab in, 300ms slab out, 250ms knock. Two things are compressed for a 18s loop and labelled as such: the wait clock runs 60× (2 real minutes in 2 seconds), and the range-change hysteresis (60s sustained to enter, 120s to leave) is collapsed to the 9.0s mark. Everything else is real.

Reduced motion: the decays become discrete holds — the completion becomes a 700ms full-ink hold, the slab appears whole instead of expanding, the knock is a single step. Nothing is lost, because the information in this design lives in which glyph is showing, not in the transitions: cursor height, figure, unit, weight, index, slab. The transitions only ever said “look now”.
